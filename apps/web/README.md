# Frontend — `apps/web`

Aplicación web de **La Casa del Jean V2** construida con **Angular** y **Tailwind CSS**.

- **Fase 0:** Scaffolding base (`Dockerfile` placeholder con Nginx no-root en puerto `8080`).
- **Fase 1+:** Inicialización del workspace Angular, sistema de diseño con Tailwind CSS, catálogo público y panel administrativo.
