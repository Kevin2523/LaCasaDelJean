# Backend API — `apps/api`

Servicio API de **La Casa del Jean V2** sobre **FastAPI**, **PostgreSQL** y **Pillow**.

- **Fase 0:** Scaffolding base (`Dockerfile` no-root, `requirements.txt` mínimo, montaje de `/app/storage/media`).
- **Fase 1+:** Endpoints REST, migraciones Alembic, autenticación, procesamiento de imágenes con Pillow y persistencia en PostgreSQL.
